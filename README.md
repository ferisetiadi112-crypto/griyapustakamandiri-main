# Orbital Foundation

Create the initial UI/UX foundation for a new web platform called "Hey5050".

IMPORTANT:

This phase is ONLY for the visual foundation, UX architecture, responsive layout, navigation structure, design system, and public-facing pages.

Do NOT implement TikTok OAuth, TikTok API integration, Content Posting API, database logic, authentication backend, API endpoints, or real user functionality yet.

The goal of this phase is to establish a premium, futuristic, clean, highly polished visual foundation that can later become the main application platform.

==================================================

1. CORE CONCEPT — HEY5050

==================================================

Hey5050 represents a vision of technology in the year 5050.

It is a futuristic technology platform built around the idea that humans and intelligent technology work together seamlessly.

The website should feel like entering a futuristic orbital technology station in the year 5050 — not like a conventional SaaS website and not like a generic AI landing page.

The visual language should combine:

- futuristic space technology

- spacecraft interfaces

- orbital stations

- planetarium environments

- deep space

- artificial intelligence

- automation

- digital creativity

- advanced human-computer interaction

- clean modern product design

The result must feel:

- futuristic

- premium

- intelligent

- minimal

- sophisticated

- clean

- organized

- professional

- technologically advanced

Avoid making it look like a gaming website.

Avoid excessive neon.

Avoid excessive glowing effects.

Avoid clutter.

Avoid generic cyberpunk aesthetics.

The future should feel believable, elegant, and technologically mature.

Think:

"NASA-inspired future technology + premium modern SaaS + spacecraft command interface + planetarium"

rather than:

"cyberpunk gaming website".

==================================================

2. BRAND PHILOSOPHY

==================================================

The name "HEY5050" represents communication between humans and the future.

The platform should communicate this philosophy:

"Technology from the future, designed for humans today."

The website should visually communicate that Hey5050 is building the foundation for future digital creation, intelligent automation, and connected technology.

Do not make TikTok the identity of Hey5050.

TikTok is only one possible integration inside the platform.

The public website must therefore remain platform-oriented rather than TikTok-oriented.

==================================================

3. GLOBAL VISUAL DIRECTION

==================================================

Use a dark futuristic visual foundation.

Primary environment:

- deep space black

- very dark navy

- subtle blue-black gradients

- extremely subtle atmospheric gradients

Accent colors should be restrained:

- electric cyan

- cool blue

- subtle violet

Use accent colors primarily for:

- active navigation

- buttons

- status indicators

- important interactive elements

- subtle interface highlights

Do NOT make the entire interface neon.

Typography should be modern and highly readable.

Use a contemporary sans-serif font system.

Headings should feel futuristic but remain professional.

Body text must have excellent readability and spacing.

Use generous whitespace.

Use a strong visual hierarchy.

==================================================

4. FUTURISTIC ENVIRONMENT

==================================================

The homepage should visually suggest a futuristic orbital environment.

Possible visual motifs:

- subtle planetary horizon

- distant planet

- orbital rings

- spacecraft silhouettes

- star field

- subtle atmospheric glow

- geometric navigation lines

- futuristic HUD-inspired details

- constellation-like data points

- subtle grid structures

These elements must remain subtle and elegant.

Do not overwhelm the content.

The interface should look like a sophisticated technology platform operating inside a futuristic space environment.

Use layered depth:

background

→ atmosphere

→ subtle orbital/planetary elements

→ interface panels

→ content

→ controls

==================================================

==================================================

==================================================

13. DESIGN SYSTEM

==================================================

Create a reusable design system.

Define:

- color tokens

- typography scale

- spacing system

- border radius

- cards

- buttons

- navigation

- badges

- status indicators

- input fields

- modal styles

- dashboard panels

Cards should use:

- subtle transparency

- dark surfaces

- thin borders

- restrained shadows

- subtle gradients

Avoid excessive glassmorphism.

Use glass effects only where they improve hierarchy.

Buttons should be elegant and compact.

Primary button:

bright but controlled futuristic accent.

Secondary button:

dark transparent surface with subtle border.

==================================================

14. MICRO INTERACTIONS

==================================================

Design the UI so it is ready for subtle future animation.

Examples:

- slow orbital movement

- subtle star movement

- gentle gradient movement

- hover elevation

- soft border illumination

- navigation transitions

- smooth section transitions

Animations must be:

- slow

- elegant

- subtle

- professional

Do NOT create flashy animations.

Respect reduced-motion accessibility.

==================================================

15. RESPONSIVE DESIGN

==================================================

The website must be designed mobile-first.

It must look excellent on:

- mobile phones

- tablets

- laptops

- large desktop screens

On mobile:

- navigation becomes a clean mobile menu

- cards stack naturally

- typography scales correctly

- planetary background remains lightweight

- content remains readable

- no horizontal overflow

- buttons remain easy to tap

The mobile experience should feel like a premium futuristic mobile interface, not a compressed desktop website.

==================================================

16. UX PRINCIPLES

==================================================

Follow these principles:

1. Clarity over decoration.

2. Futuristic but understandable.

3. Premium but approachable.

4. Strong visual hierarchy.

5. Consistent spacing.

6. Minimal visual noise.

7. Accessibility.

8. Responsive by default.

9. Reusable components.

10. Scalable architecture.

Every section must have a clear purpose.

==================================================

17. IMPORTANT BRAND RULE

==================================================

Hey5050 must NOT look like:

- a TikTok clone

- a social media dashboard

- a generic AI landing page

- a cryptocurrency website

- a gaming website

- a cyberpunk website

- a generic SaaS template

Hey5050 should look like:

"A serious technology platform from the future."

The year 5050 should be expressed through the atmosphere, interface language, spatial environment, and technology philosophy — not through excessive futuristic decoration.

==================================================

For this phase, build the complete visual foundation including:
